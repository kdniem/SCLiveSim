# ADR 0002: Licensing

- Status: accepted
- Date: 2026-10-23

## Decision

| Part | License |
| --- | --- |
| Code | Apache-2.0 |
| Core schema (`schema/`), scenario files (`scenarios/`) | CC BY 4.0 |
| Data generated by simulation runs | CC0 1.0 |
| Third-party datasets | Their original license; only redistributed if allowed |

- Apache-2.0 over MIT for its explicit patent grant and the `NOTICE` mechanism,
  which we use for dataset attribution.
- No dependency under the Business Source License or another non-OSI license in
  the core. Such tools (e.g. SDV) may only ever be optional plugins.
- Every new dependency and dataset has its license checked and named in the PR.

## Datasets

- **DataCo Smart Supply Chain** (Mendeley Data, DOI 10.17632/8gx2fvg2k6.5):
  CC BY 4.0, checked 2026-10-23. Redistribution would be allowed with
  attribution, but we still do not commit the raw CSV: it is large and contains
  personal-looking customer fields. Users download it into `data/raw/`; the
  adapter drops names, e-mails, passwords and street addresses and uses
  pseudonymous IDs instead.
