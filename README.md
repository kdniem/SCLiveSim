# SC LiveSim

**Live supply chain data for apps that need something that moves.**

SC LiveSim is an open-source engine that streams supply chain data (orders,
shipments, inventory, disruptions) through one open schema and one event
stream. Control towers, risk tools, ETA trackers and dashboards can plug into
it instead of loading static CSVs.

> **Status: Phase 1 (Replay MVP), work in progress.** The quickstart below
> covers what exists today and grows with each work package.

## How it works

```
Inputs (public datasets, later: scenarios, your own data)
  → Engine (Python): Replay | Simulation (later) | Calibration (later)
  → PostgreSQL: core schema + append-only event log
  → Access layer (FastAPI): REST, SSE stream
  → Consumers: control tower, risk tool, notebooks
```

Phase 1 replays the public **DataCo Smart Supply Chain** dataset as if it were
happening now, at a configurable speed and with a seed for reproducible runs.

## Quickstart

Requirements: Docker with Compose, and [uv](https://docs.astral.sh/uv/) for development.

```bash
git clone https://github.com/kdniem/SCLiveSim.git
cd SCLiveSim
cp .env.example .env
docker compose up -d        # starts PostgreSQL 16
```

Development checks:

```bash
uv sync
uv run ruff check . && uv run ruff format --check .
uv run mypy
uv run pytest
```

## Repository layout

| Folder | Content |
| --- | --- |
| `schema/` | Core schema: Pydantic models → JSON Schema + SQL migrations |
| `engine/` | Replay engine (simulation and calibration later) |
| `adapters/` | Importers that map public datasets to the core schema |
| `api/` | FastAPI app: REST and SSE stream |
| `examples/` | Mini control tower |
| `docs/` | Documentation, `docs/adr/` for architecture decisions |
| `data/` | Gitignored; raw downloads go to `data/raw/` |
